## 🚀 빠른 시작 가이드 (신규 입사자 권장 순서)
1. 첫날 출근 전 **01장**과 **02장(안전수칙)**을 반드시 정독합니다.
2. 현장 실무 투입 전 **04장(PDA 사용법)**과 **05장(로케이션 읽기)**을 숙지합니다.
3. 실무 진행 중 문의사항은 배정된 멘토에게 문의하고, 주간별로 **07장 체크리스트**를 점검합니다.
